# Localscan

Маленький додаток для рядка меню macOS, який показує всі локальні сервери розробки (`localhost:порт`), їхню пам'ять, процесор, температуру процесора й корпусу, і дає зупинити або перезапустити проєкт одним кліком.

*A macOS menu-bar app that lists every process listening on a local TCP port, with memory, CPU, case and SSD temperature, and one-click stop/relaunch. The interface follows your system language: Ukrainian on a Ukrainian Mac, English everywhere else.*

## Що показує

- **Запущені сервери**: порт, фреймворк (Next.js, Vite, FastAPI, Django, Ollama, PostgreSQL, Docker-контейнер…), папка проєкту, час роботи, пам'ять разом із дочірніми процесами, навантаження на процесор.
- **Картка сервера** (по кліку): повний шлях, кнопка «Відкрити у браузері», «Показати у Finder», дочірні процеси, пік пам'яті за сесію.
- **Зупинка** сервера з підтвердженням прямо в картці. Якщо процес ігнорує звичайну зупинку, додаток каже про це і пропонує примусову.
- **Перезапуск** працюючого сервера тією ж командою в тій же папці.
- **Зависання.** Жовта крапка, якщо сервер довго тримає процесор; червона, якщо не відповідає на запити. Веб-сервери перевіряються самі, решту можна перевірити кнопкою. Попередження в шапці й трикутник у рядку меню.
- **Зупинені проєкти**: усе, що додаток бачив раніше, з командою запуску. Кнопка «Запустити» піднімає проєкт знову; якщо порт зайнятий, пропонує вільний порт або зупинити того, хто його тримає.
- **Графік пам'яті** за останню годину з двома кривими: вся система і окремо ваші локальні сервери, з позначкою піку.
- **Процеси**: посилання на графіку відкриває список додатків, що тримають понад 1 ГБ, пораховано як у Моніторингу системи.
- **Температура** у заголовку: CPU (найгарячіше ядро), GPU, корпус (розрахункова температура поверхні, те, що відчуває рука) і SSD; акумулятор у підказці. У рядку меню: кількість серверів, сумарна пам'ять і CPU.
- **Запуск разом із Mac** (галочка в нижній частині вікна).
- **Дві мови**: інтерфейс перемикається сам за мовою системи, українська або англійська.

## Вимоги

- macOS 13 Ventura або новіша.
- Apple Silicon або Intel (універсальна збірка).

### Підтримка чипів

Ключі температурних датчиків різні в різних поколіннях, тому правила підбору враховують кожне:

| Чип | Ядра CPU | Графіка | Перевірено |
|---|---|---|---|
| M1 | `Tp…` (варіант `…a`) | немає в SMC, береться з IOHID | на живому Mac |
| M2 | `Tp…` | `Tg…` | за таблицею Stats |
| M3 | `Te…`, `Tf0…`, `Tf4…` | `Tg…`, `Tf1…`, `Tf2…` | за таблицею Stats |
| M4, M5 | `Tp…`, `Te…` | `Tg…` | M5 на живому Mac |
| Intel | `TC…` | `TG…`, `TCGC` | за таблицею Stats |

На частині Mac кожен датчик є у чотирьох варіантах (`…a`, `…b`, `…x`, `…z`): живе значення лише в `a`, решта — максимуми, тому вони відкидаються. Назви звірено з таблицею датчиків відкритого додатка [Stats](https://github.com/exelban/stats). На живому залізі перевірено MacBook Air M5 і MacBook Air M1; на решті поколінь очікується, що спрацює, але це не підтверджено. Якщо якийсь показник не з'явився, надішліть звіт про датчики. Додаток пише його сам у `~/Library/Application Support/Localscan/Звіт про датчики.txt` і оновлює раз на п'ять хвилин. Дістати його можна правою кнопкою на заголовку «Localscan»: «Показати звіт у Finder» відкриє теку з готовим файлом, «Скопіювати звіт про датчики» покладе те саме в буфер обміну. У звіті лише модель Mac, чип, версія macOS і значення датчиків; нічого про ваші проєкти туди не потрапляє.

Решта додатка від покоління чипа не залежить: пошук серверів працює через `lsof` і `ps`, які однакові на всіх Mac.

## Встановлення

1. Завантажте `Localscan-x.y-macOS.zip` зі сторінки [Releases](../../releases).
2. Розпакуйте і перенесіть `Localscan.app` у папку «Програми».
3. Запустіть. Іконка з'явиться у верхній панелі біля годинника; у Dock іконки немає, так і задумано.

> **macOS заблокує перший запуск**, бо додаток поки підписаний без сертифіката Apple. Відкрийте Системні параметри → Конфіденційність і безпека, знайдіть внизу повідомлення про Localscan і натисніть «Все одно відкрити». Або в Терміналі:
> ```bash
> xattr -dr com.apple.quarantine /Applications/Localscan.app
> ```

## Збірка з коду

Потрібен Xcode 26 або новіший (безкоштовний у App Store).

```bash
git clone https://github.com/Golens/localscan.git
cd localscan
open Localscan.xcodeproj
```

Далі ▶ (Cmd+R). Усі налаштування вже в проєкті: App Sandbox вимкнено (інакше додаток не бачить процеси і датчики), `LSUIElement = YES`, підпис «Sign to Run Locally», тому Apple ID для запуску не потрібен.

Щоб зібрати універсальний Release із командного рядка:

```bash
xcodebuild -project Localscan.xcodeproj -scheme Localscan -configuration Release ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO build
```

## Як це працює

- Раз на 3 секунди у фоні: `lsof -iTCP -sTCP:LISTEN` знаходить процеси, що слухають порти, один виклик `ps` дає пам'ять, процесор і дерево дочірніх процесів, ще один `lsof` і `ps` дають папку, команду запуску й час старту для всіх знайдених. Повне сканування триває близько 0,1 с.
- Температура читається з контролера SMC через `AppleSMC` (так само роблять Stats, iStat Menus, TG Pro): ядра CPU `Tp*`/`Te*`, GPU `Tg*`, поверхня корпусу `TVS0`/`TVS1`, SSD `TH0x`, акумулятор `TB*`. Показується найгарячіший датчик групи. Якщо SMC недоступний, резервно читаються датчики кристала через `IOHIDEventSystemClient`. Обидва інтерфейси не є публічним API Apple, тому додаток не для App Store.
- Чому CPU і корпус не збігаються: датчики ядер реагують за секунди (35° → 88° за 40 с під навантаженням і назад), а корпус має теплову інерцію і гріється хвилинами. Тому «тепло під рукою» краще показує «Корпус», а не CPU.
- Історія проєктів і графік зберігаються у `~/Library/Application Support/Localscan/state.json`.
- Зупинка надсилає `SIGTERM` процесу і його дочірнім процесам. Повторний запуск виконує збережену команду через `zsh -lc` у папці проєкту; інший порт передається змінною `PORT`.

## Структура

| Файл | Що робить |
|---|---|
| `LocalscanApp.swift` | `MenuBarExtra`, підпис у рядку меню |
| `PopoverView.swift` | вікно: заголовок, картки статистики, графік, список |
| `Rows.swift` | картки запущених і зупинених проєктів, модель «одна розкрита за раз» |
| `Monitor.swift` | таймер, стан, дії (зупинити, запустити, автозапуск) |
| `ProcessScanner.swift` | пошук серверів через `lsof`/`ps`/`docker` |
| `Sensors.swift` | температурні датчики через IOHID |
| `Models.swift`, `Store.swift`, `Glass.swift` | моделі, збереження, стилі |

## Відомі обмеження

- Без Developer ID і нотаризації macOS показує попередження при першому запуску на чужому Mac (див. «Встановлення»).
- Docker-контейнери визначаються, лише якщо в системі є `docker` у `/usr/local/bin` або `/opt/homebrew/bin`.
- На Intel-маках ключі SMC інші (`TC0P`, `TG0D`, `Ts0P`…); передбачено резервні префікси, але не перевірялось. Кнопка «датчики?» у заголовку виводить повний список датчиків, надішліть його в Issue.
- Якщо один процес слухає кілька портів, він показується окремою карткою для кожного порту.
